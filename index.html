Navegador remoto

Um clique inicia o Codespace e abre direto o Firefox remoto, sem passar pelo VS Code.

Configuração única

Para o launcher poder ligar/desligar seu Codespace sem a tela Resume, ele precisa de um token do GitHub limitado ao Codespaces.

  1. Abra o botão abaixo para criar o token com as permissões já preenchidas.
  2. Em Repository access, escolha Only select repositories e selecione apenas centralmidia.
  3. Gere o token, copie e cole aqui. Não envie o token em chat.
CRIAR TOKEN NO GITHUB
O token é salvo somente no armazenamento local deste navegador e é enviado diretamente para api.github.com. Ele não é salvo no repositório nem enviado ao GitHub Pages.
