Configuração do GitHub

Configuração única deste navegador.

Para o launcher ligar e desligar seu Codespace sem a tela Resume, ele usa um token limitado ao Codespaces.

  1. Abra o botão abaixo para criar o token com as permissões preenchidas.
  2. Em Repository access, escolha Only select repositories e selecione apenas centralmidia.
  3. Gere o token, copie e cole aqui. Não envie o token em chat.
Criar token no GitHub
O token fica apenas no armazenamento local deste navegador e é usado diretamente com api.github.com. Ele não é salvo no repositório.

Configuração do computador

Configuração única do RustDesk neste navegador.

Quando o RustDesk estiver instalado no Zorin, coloque aqui apenas o ID do RustDesk. A senha nunca é salva neste launcher.

Ao clicar em Abrir computador, o launcher abre o cliente web oficial do RustDesk em outra aba e copia seu ID para a área de transferência. Desligar computador será conectado ao agente local do Zorin na próxima etapa; ele significará desativar o acesso remoto, não desligar fisicamente o PC.
